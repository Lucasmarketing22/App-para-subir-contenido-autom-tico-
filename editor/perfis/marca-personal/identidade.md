# Identidad — marca personal
Origen: referencias 2026-11-11. La identidad real la pone cada cliente (logo/colores de la marca); esto es el punto de partida.
- Tipografía subtítulos: sans muy pesada (Inter Black / similar), MAYÚSCULA; variante cursiva extra negrita para ganchos (refs 4, 6).
- Tipografía de títulos de dato: condensada gigante (tipo Anton/Bebas) para números y cifras (ref 3).
- Color de acento por defecto: amarillo #FFD400 (refs 2, 3); rojo para lo negativo/advertencia (refs 4, 6). Blanco con contorno/sombra negra para todo lo demás.
- Para clientes con marca (ej. Cuadro Barcelona): sustituir el amarillo por el color de marca si lo hay.
- Nunca: subtítulos en bloques de 3 líneas; fuentes finas sobre fondos claros sin contorno.
